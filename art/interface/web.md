# Request: Spider web

- **Sprite id:** `web` (deliver `web.png`)
- **Kind:** interface icon
- **Read first:** `art/README.md` (format and style rules)
- **References:** `src/img/sprites/interface/web.png` (current version), `src/img/sprites/monsters/tomb.png` (object style)

## Where it appears

Shown in place of the **Web spider** while the hero holds a weapon: the spider hides in its web and can be walked through.

## What it must look like

- A grey spider web (`#8b9bb4` / `#5a6988`), round, with spokes and rings, a lot of transparency.
- Shown in place of the Web spider while it hides, so a player should guess "something is in there".

## Do not

- Do not add a background or a frame: only the icon, on transparency.
- Do not draw the spider.

## Deliver

`web.png` (at least 256 × 256, transparent; see `art/README.md`). Optionally up to three variants as `web-1.png`, `web-2.png`, `web-3.png`.
